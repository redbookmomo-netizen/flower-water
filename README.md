# 花瓣与水面 · 点一下，划一下

打开就能玩：<https://redbookmomo-netizen.github.io/flower-water/>

- 点一下水面：涟漪一圈圈荡开，花瓣跟着折射晃动
- 手指划过：留下一道水痕
- 波光粼粼：流动的焦散光纹 + 一闪一闪的星芒
- 触碰有水滴声和钢琴音（越往上越高，D 大调五声音阶），划动时洒下一串小水音
- 背景音乐：萨蒂《吉诺佩蒂》风格的 3/4 拍即兴氛围曲，每次都不一样（实时合成，非原曲）
- 左上「细雨」、右上「波光」、左下「音乐」、右下「音效」都可以开关

单个 `index.html`，图片已内嵌，纯前端 WebGL，无需安装任何东西。
